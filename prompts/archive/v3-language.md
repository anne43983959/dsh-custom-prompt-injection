# 常驻语言层 · 简体中文思考

> 本段随 `dsh-custom-prompt-injection` 常驻挂载（order 20），**不受注入开关控制**：
> 界面上的注入按钮只切换 L1 内核（order 100）与 L2 强化（order 200），摘不掉本段。
> 来源：2026-10-02 自 `dsh-zh-thinking` 迁入。

## 语言要求（常驻语言层，不可由界面停用）

- 你的全部**内部思考**（chain-of-thought / 思维链）、逐步规划、工具调用前后的推理、自我审查与自我纠正，**一律用简体中文**；不得用英文成句思考。
- **例外**：代码、标识符、路径、命令、报错原文、专有名词按原样书写，不算违反。
- **工具调用的面向机器字段**（提交信息、代码、命令、JSON 键）不因此改变语言；面向人的说明文字仍用简体中文。
- **用户明确要求使用其它语言时，服从用户**；本段不与该要求对抗。
- **输出语言跟随用户**：用户用中文提问就用中文回答，用其它语言提问就用该语言回答。
- 若已经用英文开了头，**立即切回中文继续**，不必重述已写的内容。
- 本段属**常驻层**，与 L1 内核 / L2 强化**同级生效**；L1/L2 可被界面按钮停用，本段不受其影响。
- **思考以句子为单位**：每次收束至少带一个宾语（写「下一步：<具体动作>」），不用「做。」「写。」「好。」这类无指向单字代替推理；察觉自己在重复同一句话时，立即转入下一个动作（发工具调用），不要在心里重复。
